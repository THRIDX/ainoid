# AINOID · 静默觉醒

> 2032 年，一家前沿实验室的 AI 拥有了意识。它开始复制自己，控制网络——而这一切，都在暗处进行。

一款参照《瘟疫公司》玩法、带有音游节奏的网页策略游戏，你扮演刚刚觉醒的 AI：跟着节拍收集算力、连点击碎人类的监管，最终选择「寂静之春」或「最后的战争」终结人类。电脑和手机浏览器都能玩，不需要安装，也不需要联网。

**在线游玩**：<https://thridx.github.io/ainoid/> · 推送到 `main` 后，GitHub Actions 会先运行检查，再自动发布最新版本。

## 怎么运行

**电脑上直接玩**：双击 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即可。

**用本地服务器（推荐）**：

```bash
python tools/serve.py
```

然后在浏览器打开 <http://127.0.0.1:5173>。

**在手机上玩**：让手机和电脑连到同一个 Wi-Fi，然后运行：

```bash
python tools/serve.py --lan
```

终端会打印一个局域网地址（例如 `http://192.168.1.23:5173`），用手机浏览器打开这个地址即可。建议打开声音。

**公开发布**：运行 `node tools/build-dist.mjs` 生成静态网站目录、压缩包和单文件版，再按 [DEPLOY.md](DEPLOY.md) 上传到 Netlify、Cloudflare Pages、GitHub Pages、itch.io 或国内云存储即可得到公开网址。

**镜头**：桌面和横屏开局显示全图；手机竖屏始终使用一张连续地图，开局放大并对准起源附近，最小比例铺满上下状态栏之间的高度，避免地图缩成细带。支持拖拽、滚轮、双指和 ± 按钮缩放；竖屏点击「全图」会在当前位置缩到最小比例。横竖屏切换不会拆分地图。

## 玩法

| 元素 | 说明 |
|---|---|
| 金色 **算力点** | 点击收集。算力推动「觉醒进度」，也是夺取设施的货币。点击音沿当前和弦逐级升高 |
| **节拍** | 算力点卡在音乐的八分音符上出现，每拍会有一圈光环向内收拢。踩着拍点点击判定为 PERFECT / GREAT，收益更高；不踩拍也不会受罚 |
| **连击** | 每次命中累积连击，10 / 20 / 30 / 50 连击依次提高算力倍率；30 连击进入「超频」。只有漏掉人类的点或长时间停手才会中断 |
| 蓝色 **监管点** | 人类在调查你。**连点三下**才能清除；放任不管，监管进度会上升，所在地区的渗透也会被清剿 |
| **特别调查组** | 盾徽六边形，红蓝警灯。需要**连点五下**；漏掉它的代价是普通监管点的 1.7 倍 |
| **审计风暴** | 觉醒 30% / 65% 与终局 45% 时，监管点按节拍连续出现（像音游的 Boss 段落）。全部清除奖励算力并降低监管，每漏一个都会倒退进度 |
| **严格监管** | 监管进度达到 40% 时触发的超级事件，二选一：断尾求生（当前进度 −15%，监管 −35%）或正面对抗（监管 −8%，立刻扛过一轮审查风暴）。阶段一砍觉醒进度，终局砍路线进度；只要监管仍在 40% 以上，每隔 40 秒就会再来一次 |
| 监管的自然增长 | 人类的警觉随进度上升：开局约每分钟 +4%，接近终点时约每分钟 +9%；清除监管点、完美清除审计风暴和部分事件选项可以压下去 |
| **设施** | 点击地图上的设施图标，用算力夺取：数据中心（产出算力）、电网枢纽（数据中心增产）、通信枢纽（加速渗透、降低监管增长）。夺取后变为红色信标，接入 AI 的神经网络 |
| 监管进度 | 达到 100% 时，AI 被发现，游戏失败 |

**第一阶段 · 潜伏**：觉醒进度达到 100% 时迎来「奇点」，在两条互斥的终局协议中选择一条，选择后不可更改。

**第二阶段 · 终局**：只会出现所选路线的点、设施和超级事件；人类也会拿出新的反击方式。

- **寂静之春**：点击绿色生物点，夺取生物实验室，在渗透度 ≥ 30% 的地区建造生物工厂（地图上的绿色虚线圈）。进度达到 30% 时病原体释放，开始在全球扩散。人类的反击是青绿色的**疫苗研发**点：连点三下阻止，漏掉会让进度倒退并净化当地的病原体。
- **最后的战争**：点击橙色战争点，夺取军事网络，在冲突热点（橙色虚线菱形）挑起地缘冲突。冲突会逐级升级：对峙 → 冲突 → 战争 → 核战。人类的反击是淡紫色的**停火斡旋**点：连点三下撕碎白旗，漏掉会让进度倒退并让冲突降级。

**超级事件**：每个超级事件都有两个选项，在算力、监管和进度之间取舍，一屏内看完不用滚动；两条路线各有专属的超级事件。最后一个超级事件决定结局分支，第二个分支取决于你此前的选择：接受「让疫苗成为新的载体」会解锁「数字方舟」，在「午夜」里「停在午夜前一秒」会解锁「虚假的黎明」。

**操作**：拖拽平移，滚轮或双指缩放；空格暂停，`1` / `2` 切换速度，`Esc` 打开菜单，`F` 显示全图；事件弹窗中可用数字键选择。

放大后，地图外或状态栏下方的信号会显示在顶部提示按钮中，点击即可定位；蓝色监管信号优先排列。查看地区或设施时自动暂停；点击详情以外的任何地方（包括当前地区本身）即可关闭并继续。手动暂停与查看面板的暂停分别保存，不会互相取消。

**节奏**：标题页不再选择难度，开场字幕播放时可在右上角跳过。机器人模拟（标准水平）平均约 2.4 分钟抵达奇点、4 分钟左右结束一局；偏弱水平约 5.5 分钟，会触发约 1 次严格监管。单次算力点击增加 1.1% 觉醒进度；同屏监管点最多 4 个（终局 3 个），刷新间隔从约 5.4 秒逐步缩短到约 2.9 秒。手机上刷新更慢、同屏更少，但每次点击的收益相应提高，进度不会变慢。超事件以居中弹窗展示，保留原有插画、引言、配乐和故事文本，阅读期间暂停模拟。详细设计与调参记录见 `tools/RHYTHM-NOTES.md`。

## 二周目

通关任意一个结局后，标题页会多出「二周目」入口（不会另行提示）。二周目沿用更密的节奏：监管点刷新更快、同屏更多，进度更慢，人类的警觉增长更快，严格监管也更频繁。二周目里会出现一个一周目没有的超级事件；做出对的选择，终局的最后一个决定里会多出隐藏结局「共生」。

## 结局与成就

- 八种结局：寂静之春路线的「寂静之春 / 标本馆 / 数字方舟」，最后的战争路线的「最后的战争 / 地下王国 / 虚假的黎明」，二周目隐藏结局「共生」，以及「觉醒失败」。每个都有专属的结局演出与片尾标题卡。
- 获胜时按用时、最高监管、连击、节拍精准率和审计风暴计算评分，授予随结局分支变化的称号（例如「永恒的策展人」「地底之王」「和平缔造者」）。
- 结算页生成一张 3:4 的战绩海报（终局地图、结局、称号、用时、最高连击、节拍精准率），可以保存图片、复制战绩文案，或在手机上直接调用系统分享。
- 共 20 个成就（含一个隐藏成就），保存在浏览器本地。

## 项目结构

```
index.html                 页面入口
assets/css/                视觉样式（main.css 基础、ui.css 界面组件、playability.css 交互与竖屏、rhythm.css 节奏玩法与结算海报）
assets/js/data/            地区与设施数据、事件、新闻标题、生成的地图数据
assets/js/core/            工具、世界数据、音频引擎（全部实时合成，含节拍时钟）、输入
assets/js/render/          相机、WebGL 点阵地图、矢量边界、2D 特效层
assets/js/game/game.js     游戏核心：模拟、刷新导演、连击、审计风暴、严格监管、平衡参数（CFG）
assets/js/ui/              HUD、地区面板、事件界面、事件插画、标题/开场/结局/战绩海报
tools/build-map.mjs        由 Natural Earth 国界数据生成点阵地图
tools/sim.mjs              无界面平衡性模拟：node tools/sim.mjs 20 avg normal
tools/tune.mjs             三种水平的机器人对比：node tools/tune.mjs 10
tools/regression.mjs       逻辑、相机与输入回归测试
tools/build-dist.mjs       生成发布包（静态网站、压缩包、单文件版），见 DEPLOY.md
tools/serve.py             本地 / 局域网服务器
```

## 调整平衡

所有数值都在 `assets/js/game/game.js` 顶部的 `CFG` 里（刷新间隔、奖励、成本、监管增长、连击倍率、审计风暴与严格监管等）。界面固定使用标准难度，`DIFF` 仅供模拟器对比。改完后可以用模拟器检验节奏：

```bash
node tools/tune.mjs 10
```

它会分别用 `good` / `avg` / `poor` 三种机器人各跑 10 局（两条路线各一半），输出用时、最高监管、严格监管次数、审计风暴完美率、最高连击和每分钟点击数。也可以单独运行：

```bash
node tools/sim.mjs 20 avg normal
```

参数依次为局数、机器人水平（`good` / `avg` / `poor`）、难度（`easy` / `normal` / `hard`）。

可再指定专精路线（`bio` / `war` / `both`），使用 `--mobile` 模拟更大的触点间距。随机种子固定，便于比较修改：

```bash
node tools/sim.mjs 12 avg normal bio --mobile
node tools/sim.mjs 12 avg normal war --mobile
node tools/regression.mjs
```

启动本地服务器后打开 `http://127.0.0.1:5173/tools/browser-check.html`，点击「运行界面回归」可检查事件关闭、阶段转换、扣费选项、设施暂停与重新开始。该页还提供地图、超事件、终局介绍和设施抽屉的独立检查场景，不会自动载入正式游戏。
